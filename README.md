# Voorstel De Roode Leeuw

Ontwerpvoorstel voor de nieuwe site van Restaurant De Roode Leeuw, 's-Gravenweg 379, Capelle aan den IJssel. Dit is **niet** de site van het restaurant.

De pagina staat op https://douxejim.github.io/roode-leeuw-voorstel/ en is met `noindex` uit de zoekmachines gehouden.

De reserveerknop is aangesloten op Zenchef 367299, de echte agenda van het restaurant. Op de contactpagina staat een waarschuwing dat doorklikken tot bevestigen een tafel in het boek zet.
